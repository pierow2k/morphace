Morphace handles size mismatches, but it cannot make every composition line
up. For example, a close-up portrait and a full-body shot may both include
detectable faces, but the resulting video will include more movement from
the background and body areas.

To create a video that focuses more closely on facial features, use the
[prep](/cli-reference/prep) command. It automatically aligns and crops
images before morphing.

The gallery below shows examples of these different morphing results.
